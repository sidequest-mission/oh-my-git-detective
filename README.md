**Oh My Git! Detective Edition** is a community-maintained fork of *Oh My Git!*, an open-source interactive game about learning Git.

## 🚀 About This Fork

This repository is maintained by **[SideQuest Missions](https://github.com/sidequest-missions)** as an active fork (`oh-my-git-detective`). Because the original upstream repository is in low-maintenance mode, this fork serves as a space for active updates, community contributions, enhanced CI/CD workflows, and new features or levels.

### Original Project & Credits

*Oh My Git!* was originally created and developed by **[bleeptrack](https://github.com/bleeptrack)** and **[blinry](https://github.com/blinry)** in 2020/2021, with support from the Prototype Fund. 

We are deeply grateful for their work in building this project. The core game design, mechanics, and initial assets remain the work of the original authors.

* Original Repository: [git-learning-game/oh-my-git](https://github.com/git-learning-game/oh-my-git)
* Play the original release binaries: [itch.io](https://blinry.itch.io/oh-my-git)
